- **2026-07-26, Round 7 review (entries 51-100 of rare_word_round7_review.md).**
  The word "splenter" at Matthew 7:3, 7:4, 7:5 replaces "beam" (Geneva 1599:
  "beame"; Oxford/1769 KJV.db: "beam") against "mote"/"dust" in all three
  verses. Zero attestation for "splenter" in Geneva1599.db or KJV.db at these
  verses per the review file's own comparison columns.
- File metadata marks this entry `src: RESTORED` — i.e. some prior process
  already substituted this word in for the base reading, meaning the
  substitution itself looks like the corruption, not a repair of one.
- **Semantic argument, not just an attestation gap**: even granting "splenter"
  as a variant spelling of "splinter," a splinter is itself small — reading it
  that way collapses the passage's entire rhetorical point, which depends on
  the mote (tiny speck) vs. beam (a whole roof-timber/plank) being wildly
  mismatched in scale. Mote/splinter would make both objects small, inverting
  the verse's hyperbole. This is a case where Axis 1 (no attestation) and
  Axis 2 (referent-scale sense breaks the source-era proverbial structure)
  point the same direction — strong flag for owner review, output as "swap to
  beam" in `references/rounds/round7/kj_round7_suggestions_51_100.md`.

  for any competing memory of this verse before treating "beam" as final — per
  Premise Revision this King James-agent verdict is advisory only, it cannot
