- **Ezra 4:13 editorial artifact**: the restored text (as quoted in `batch_5_r2_input.md`) literally reads "so thou shalt **damage/hurt** the revenue of the kings" — a visible slash between two unresolved word choices sitting in running scripture text, not a genuine variant spelling. The base `bible_databases/formats/sqlite/KJV.db` (queried directly 2026-07-29) reads **"endamage"** at this verse: "so thou shalt endamage the revenue of the kings." Geneva1599 reads "hinder the Kings tribute" (its own synonym for the same act). "endamage" (Old French "endamager") is a genuine, attested period verb — the artifact should be resolved back to it, not to either half of the slash. Flagged to the main agent for the apply-migration workflow; not something this agent can fix directly (restored verse text, not a synonym-review call).
- **Four WHITELIST recommendations** (Batch 5 token triage round 2, 2026-07-29), all single-referent nouns with continuous multi-witness attestation and no true one-word substitute:
  - **omer** — transliterated Hebrew dry-measure; every period witness (Geneva "Omer," Wycliffe "gomor") keeps it as a loanword, same category as previously-whitelisted "gerahs"/"shekel."
  - **tenons** — carpentry joinery term (paired with mortise/sockets in the tabernacle-board passage); Wycliffe's independent cognate "dentyngis" confirms Middle-to-Early-Modern continuity.
  - **snuffers** — the candlestick's wick-trimmer (Exod 37:23, I Kings 7:50, II Kings 12:13). Protecting this now heads off a repeat of the "tongs" mis-swap a prior batch (batch 4) already had to flag at Exodus 25:38 — same implement, same risk.
  - **pisseth** — the Hebrew idiom "him that pisseth against the wall" (I Sam 25:22/34, I Kings 14:10), attested verbatim in Geneva and by cognate in Wycliffe at all three verses. Flagged specifically because its bluntness (a deliberate Hebrew euphemism-for-"every male") is exactly what a future "modernize the crude bits" pass would target — whitelisting now protects the KJV's own deliberate register.
- **Daniel 4 Geneva1599 versification runs ahead of KJV** for a stretch of the chapter: Geneva's quoted text at "Daniel 4:15" (per book_id/chapter/verse lookup) is actually Nebuchadnezzar's dream-interpretation request (~KJV 4:18), and at "Daniel 4:23" is content resembling ~KJV 4:26. This is a new corpus-quirk finding, structurally like the already-documented Psalms Vulgate-numbering offset (see `corpus-quirks.md`) but in Daniel rather than the Psalter — worth adding there if a future task hits Daniel 4 witness lookups and gets confusing mismatches. Not yet confirmed exactly how many verses the offset runs or where it resolves; flag and re-verify before relying on it.
- **Mankind (Lev 18:22, 20:13) semantic-shift note**: KJV's "mankind" there means "a male person" (the older, narrower sense), not "humanity" — Geneva itself paraphrases both verses to "the male," showing even 1599 readers felt the sense needed clarifying. Job 12:10's "mankind" in the same batch is the ordinary "humanity" sense, verbatim-attested in Geneva. A genuine Capability-4 glossing case, not a corruption — worth remembering if "mankind" recurs in a future word-review pass so the two senses aren't conflated.
