# Agent Instructions

All coding and research agents working in this repository must read and follow
[`CLAUDE.md`](./CLAUDE.md). It is the canonical operational guide for the
project, despite its historical tool-specific filename.

Do not treat this file as a second, independent set of rules. Project mission,
evidence policy, preservation requirements, workflows, validation, and the
map of relevant reference documents are maintained in `CLAUDE.md`. Follow any
more-specific `AGENTS.md` found below the directory in which you are working;
otherwise, `CLAUDE.md` governs repository-wide work.
